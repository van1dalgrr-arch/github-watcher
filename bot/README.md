# bot — Telegram-бот с командами

Пишем вместе: автор репозитория + Claude. Сейчас здесь каркас — бот запускается,
отвечает на `/start` и `/help`, остальные команды — заглушки «🚧 пишем вместе».

```sh
gw bot      # запустить; работает, пока открыт терминал (Ctrl+C — остановить)
```

Токен и chat id — те же, что для уведомлений (`gw telegram <token>`). Бот отвечает только тебе:
сообщения из чужих чатов он молча игнорирует (`onlyOwner` в `bot.go`).

## Что где

```
bot/
  bot.go                  запуск, меню команд в Telegram, защита «только хозяин»
  internal/
    command/command.go    список команд: имя, описание, обработчик
    keyboard/keyboard.go  кнопки под сообщениями и разбор нажатий ("merge:me/app:42")
```

Библиотека — [go-telegram/bot](https://github.com/go-telegram/bot). Для запросов к GitHub у команд уже есть
`Deps.GH` — тот же клиент, что у TUI: `PullRequests`, `Issues`, `WorkflowRuns`, `MergePR`, `RerunWorkflow`…

## План

1. `/prs` — список открытых PR со статусом CI
2. кнопки под PR: «Смёржить», «Открыть на GitHub»
3. `/merge 42` — с подтверждением кнопкой «Да / Нет»
4. `/runs` и кнопка «Перезапустить» под упавшим CI
5. `/status` — сводка: что упало, что ждёт ревью
6. кнопки прямо под уведомлениями от `gw notify`

Командам нужна постоянно работающая программа, поэтому бот живёт в `gw bot` (позже — внутри `gw daemon`),
а уведомления по-прежнему приходят из GitHub Actions, даже когда ноутбук выключен.
